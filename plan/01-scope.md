# 1. Scope
The baseline is a classic MOBA rule set. Every system is either part of this baseline or listed as a Brainrot original.

| Core rules | Brainrot originals |
| --- | --- |
| Level cap 25 | Clout (signature resource) |
| Ultimates unlock at 6, 11, 16 | Bull Run |
| Four abilities, three attributes | Stan (creep buff) |
| Lanes, towers, content mills, Exchange | Markdown (death transfer) |
| Boss objective with a revive reward | Resell chain |
| Delivery Drone, shops, wards, day/night | Rebrand |
| Glyph | Go Private (padlock) |
| Attribute stat rules | The Trend and Snapshot |
| Gold, XP, bounties | Tethered support, dueler tether |

Remix policy: a Brainrot original may only sit in the slot of a classic system (see section 2). It may add a decision. It may not add a new resource that nobody can read. Numbers marked UNVERIFIED are set in the balance pass. The classic numbers in this chapter are UNVERIFIED under decision 21.
