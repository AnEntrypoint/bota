# 23. Voice and banter
Voice for the twelve archetypes, a sample of the launch heroes, hero pairs, the formerly tag and item flavor. Expressive by default, loud only for Hot-take initiator.

### Rules
1. Voice follows the archetype in section 15.
2. Loaded tier: lines may use the rule 6 vocabulary from file 16 (cope, skill issue, L + markdown and similar). Its aim follows plan/16 rule 6.
3. Read path: LIVE, Stan, Hype Spike, Markdown and Resell are readable from the HUD alone. No line is the only copy of a signal, and no line claims a state the portrait, top bar or minimap does not show.
4. Hero and pair lines stay under twelve words (cap UNVERIFIED). They carry no stats.
5. Named people, brands, creators and franchises are excluded by decision 7 in plan/20.
6. Hero lines: kill plays on a kill, death on the hero's death, idle after the hero stands still outside a fight for a pause (length UNVERIFIED). Each line plays once per trigger. Per-line cooldown is 8 s (GUESS: long enough that a line does not repeat within one fight; the balance pass sets it).
7. Compact tooltips hide flavor (file 16, gag 09).
8. Verbal habits are flavor openers only; no habit gates, triggers or changes a mechanic. Tricky and Ghillie speak in records and citations, and so do the Utility and Harasser archetypes; every other hero keeps its own register within the archetype voice.

### Formerly tag

The tag is gag 05 in file 16: a small grey word after a hero name, reading "formerly" and a fixed former name. It names a Rebrand (file 05), so it only appears after one in the same match.

1. Text: "formerly Guest" for every hero and every client.
2. Colour: grey only. Never Clout violet, LIVE violet or red. The tag carries no state, no number and no stat. It never appears on the scoreboard, the minimap or the hero model.
3. Trigger: the hero has Rebranded in this match.
4. Budget: see gag 05 in plan/16.
5. Death recap: the header stays the standard Markdown line from file 16, gag 04. The tag sits on the nameplate beside it.
6. Victory screen: the tag sits beside the winning hero's name in the clean stats view. The click-and-hold fold (gag 11 in file 16) is unchanged.
7. Reduced motion: the tag is static.

Two example lines:

- Death recap: "Gigachad, formerly Guest." Header: "Your stall was marked down."
- Victory screen: "Grey, formerly Guest." Header: "Victory. Stall sold."
